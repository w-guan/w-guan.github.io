# Wenwen Guan — Personal Academic Website

A static academic website built with Astro. Personal information, research interests,
publications, and experience are maintained in `src/data/profile.ts`.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Before publishing, replace the placeholder domain in `astro.config.mjs` and
`public/robots.txt`.
