# Wenwen Guan — Personal Academic Website

A static academic website built with Astro and published at
[w-guan.github.io](https://w-guan.github.io/).

Personal information, research interests, publications, presentations, experience,
and service are maintained in `src/data/profile.ts`. Field Notes entries are maintained
in `src/data/fieldNotes.ts`, and updates are maintained in `src/data/updates.ts`.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Pushes to `main` are built and deployed to GitHub Pages automatically.
